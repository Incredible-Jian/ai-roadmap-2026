# 论文阅读记录

围绕无人机视觉任务整理相关论文，逐步建立“研究问题 → 技术方法 → 实验依据 → 局限与后续工作”的知识脉络。

## 阅读目标与规则

- 按老师要求，逐步阅读不少于 30 篇 2024 年及之后的相关顶会论文，并形成自己的技术发展脉络。
- 会议与年份需要核实；预印本、期刊论文与会议论文分开记录。
- 同一工作的论文、代码、项目网页和数据集只算一项工作。
- 导读、部分阅读、精读、复现分别记录；仅看摘要不计为完成阅读。
- 不追求逐句抄写，优先记录自己能解释的核心内容与尚未理解的问题。

## 当前理解的技术联系

```text
基础分类：图像或特征属于什么类别？
    ↓ 增加定位要求
目标检测：目标是什么，位于哪里？
    ↓ 减少人工框标注成本
点监督检测：只提供位置点与类别，如何估计目标范围？
    ↓
PointSR：改善估计出的伪框，用于训练检测器
```

这是目前的概念联系，不代表完整的历史发展顺序。后续阅读增加后，再整理不同方法之间的实际继承与区别。

## 简短笔记模板

每篇论文优先回答以下五项：

1. 解决什么问题？
2. 输入、监督信息和输出分别是什么？
3. 核心方法是什么，为什么可能有效？
4. 哪些实验支持结论，有什么适用条件？
5. 我还没有理解什么？
