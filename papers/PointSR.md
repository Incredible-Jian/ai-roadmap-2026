## 1. 解决什么问题？

无人机图像中常有密集的小目标。为每个目标标出完整检测框，需要较多人工工作。

点监督提供每个目标的位置点和类别，但没有直接提供目标的宽、高与完整范围。因此需要从点标注估计伪框，再用于训练目标检测器。

**我的理解：知道“这里有一辆车”，不等于知道“这辆车应该框多大”。**

## 2. 最重要的区别

| 概念 | 含义 |
| --- | --- |
| 点标注 | 提供目标位置点与类别，不直接提供完整范围 |
| 候选框 | 围绕标注点等信息生成的不同范围假设 |
| 伪框 | 算法选择、调整和细化后得到的估计框，仍可能有误差 |
| 真实框 | 用于监督或评估的参考标注；在该点监督训练设定下，不能直接用它挑选候选框 |

多个候选框都可能包含车辆特征，但并不都准确。例如，小框可能只包含车顶，大框可能混入道路或其他车辆，偏移框可能只覆盖半辆车。

**分类正确与定位准确是两件事。伪框经过多轮优化，也不等于已经获得真实框验证。**

## 3. 方法主线：先建立直观理解

```text
点标注与类别
    ↓
生成、调整候选框
    ↓
利用多实例学习预测粗伪框
    ↓
结合信息性负样本等机制细化伪框
    ↓
使用伪框训练目标检测器
```

目前对主要模块的理解：

- **TE 编码器：** 汇总训练过程中历史伪框的形状信息，更新锚框原型，帮助调整候选框。这里的时序指跨训练轮次的信息，不应直接理解为视频帧之间的运动信息。
- **多实例学习（MIL）：** 一组候选框与已知目标类别关联，但不能预先认定其中每一个框都是准确的目标框。
- **信息性样本收集与伪框细化：** 利用较有学习价值的负样本等信息，改善候选框选择，抑制不可靠的候选正样本。

这里只记录方法概念，具体评分、筛选规则和损失公式仍需要继续阅读。

## 4. 与我的 IoU 实验有什么关系？

```text
IoU = 交集面积 / 并集面积
并集面积 = 框 A 面积 + 框 B 面积 - 交集面积
```

在连续坐标 `xyxy` 表示下，交集左上角取 `max`，右下角取 `min`，交集宽高限制为非负。

实验中真实框为 `[0, 0, 4, 2]`：

| 候选框 | 问题 | IoU |
| --- | --- | ---: |
| `[1, 0.5, 3, 1.5]` | 太小 | 0.2500 |
| `[0, 0, 4, 2]` | 完全重合 | 1.0000 |
| `[-1, -1, 5, 3]` | 太大 | 0.3333 |
| `[3, 0, 7, 2]` | 位置偏移 | 0.1429 |
| `[5, 0, 7, 2]` | 不重叠 | 0.0000 |

这个练习帮助我理解定位质量，但不是 PointSR 方法复现。教学实验中知道真实框，不代表点监督训练时可以直接用真实框计算 IoU 来选择伪框。
