## CNN 特征观察

- 从验证集取出单张图时，`sample_image` 已是 `[C,H,W] = [1,16,16]`。用一次 `unsqueeze(0)` 补上 batch 维度，得到 `[1,1,16,16]`。
- `Conv2d` 输出 `[1,4,16,16]`。四个通道是四张特征图，最后的分类层综合这些特征区分横、竖条纹。
- **易错点**：ReLU 把负的**激活值**置零，输出形状仍是 `[1,4,16,16]`。`MaxPool2d(2)` 在各通道内对 `2×2` 区域取最大值，输出 `[1,4,8,8]`。变小的是高和宽，通道数仍为 4。
- 用 `model[0].weight.detach().clone()` 保存初始卷积权重。`detach()` 断开梯度跟踪，`clone()` 独立复制数据。种子 42 下，恢复最佳模型后，卷积权重与初始值的最大绝对差约为 `0.4572`。

## 图片、标签与 batch

- **易错点**：下标表示第几张图片，标签表示图片属于哪一类。第 3 张图的下标是 `2`，画的是横条纹，所以 `labels[2].item()` 为 `1.0`。
- `images[2, 0, 3:5, :] = 1.0` 选中第 3 张图的第 0 个通道，把下标为 `3`、`4` 的两行全部置为 1。切片包含左端、排除右端。
- `TensorDataset(images, labels)` 按相同下标取出图片和标签。`DataLoader` 使用 `batch_size=2, shuffle=False` 时，依次得到 `[2,1,6,6]` 和 `[1,1,6,6]` 两批图片，标签分别是 `[0,1]` 和 `[1]`。
