Day6：学习率、优化器与训练过程

一、今日学习目标

1. 理解学习率的含义及其对训练过程的影响。
2. 理解 SGD 和 Adam 的基本区别。
3. 理解 Batch Size、Epoch、Iteration 之间的关系。
4. 通过实验比较不同学习率下的损失变化。
5. 理解梯度清零、反向传播和参数更新的完整流程。
6. 初步了解学习率调度器的作用。

二、学习率（Learning Rate）

学习率控制模型参数每次更新的幅度，是训练神经网络的重要超参数。

梯度下降的基本公式：

w_new = w_old - lr × gradient

其中：

- w_old：当前参数。
- lr：学习率。
- gradient：损失函数对参数的梯度。
- w_new：更新后的参数。

学习率过大

- 参数更新步幅可能过大。
- 可能越过损失较低的位置。
- 可能导致损失震荡，甚至发散。

学习率过小

- 每次参数更新幅度较小。
- 可能需要更多迭代才能取得较好的结果。
- 在固定训练轮数下，模型可能尚未充分收敛。

学习率合适

通常能够使训练较稳定地进行，但合适的学习率取决于模型、数据、优化器和其他训练设置。

三、SGD 与 Adam

SGD

随机梯度下降根据当前 Batch 计算的梯度更新参数。

特点：

- 更新机制相对简单。
- 便于理解梯度下降原理。
- 训练效果对学习率等超参数较敏感。

Adam

Adam 使用梯度的一阶移动估计和二阶移动估计，自适应地调整不同参数的更新幅度。

特点：

- 通常比较容易作为神经网络的初始优化器。
- 不同参数可以获得不同的自适应更新幅度。
- 仍然需要合理选择学习率等超参数。

注意：Adam 和 SGD 的表现取决于具体任务，不能认为 Adam 在所有情况下都更好。

四、Batch Size、Iteration 与 Epoch

Batch Size

一次迭代使用的样本数量。

Iteration

一次训练迭代通常包含：

1. 取出一个 Batch。
2. 前向传播得到预测。
3. 计算损失。
4. 清空旧梯度。
5. 反向传播计算梯度。
6. 优化器更新参数。

Epoch

模型完整遍历一次训练集，称为一个 Epoch。

如果训练集有 2400 个样本，Batch Size 为 64，且 drop_last=False：

每个 Epoch 的 Batch 数量为：

ceil(2400 / 64) = 38

训练 10 个 Epoch，则总迭代次数为：

38 × 10 = 380

最后一个 Batch 只有 32 个样本。

五、PyTorch 训练流程

典型的训练代码：

model.train()

for X_batch, y_batch in train_loader:
    optimizer.zero_grad()

    predictions = model(X_batch)
    loss = criterion(predictions, y_batch)

    loss.backward()
    optimizer.step()

各步骤的作用：

- "model.train()"：将模型切换到训练模式。
- "optimizer.zero_grad()"：清空上一次迭代遗留的梯度。
- "model(X_batch)"：前向传播，得到模型预测。
- "criterion(...)"：计算预测误差。
- "loss.backward()"：计算各参数的梯度。
- "optimizer.step()"：根据梯度和优化器规则更新参数。

PyTorch 默认会累积梯度，因此每次迭代通常需要清空旧梯度。

六、训练实验：比较不同学习率

实验任务：使用线性回归拟合 y = 3x + 2，比较学习率 0.001、0.01、0.1 的训练表现。

实验控制：

- 使用相同的数据。
- 尽量保持模型初始参数一致。
- 使用相同的优化器。
- 使用相同的训练轮数。
- 记录最终 Loss 和参数估计值。

记录实际运行结果：

Learning Rate| Initial Loss| Final Loss| Final Weight| Final Bias
0.001| 待填写| 待填写| 待填写| 待填写
0.01| 待填写| 待填写| 待填写| 待填写
0.1| 待填写| 待填写| 待填写| 待填写

以上数值应根据自己的实际运行结果填写，不预先假定哪个学习率最好。

七、学习率调度器（Learning Rate Scheduler）

学习率不一定在整个训练过程中保持不变。

一种常见思路是：

- 训练初期使用较大的学习率，帮助模型较快学习。
- 训练后期降低学习率，使参数更新更加细致。

PyTorch 提供了多种学习率调度器，例如：

- "StepLR"：每隔指定的 Epoch 调整学习率。
- "ReduceLROnPlateau"：当监控指标一段时间没有改善时降低学习率。

调度器不是必需的。是否使用、如何设置，需要结合具体任务进行实验。

八、今日总结

1. 学习率影响参数更新的步幅。
2. SGD 与 Adam 的参数更新规则不同。
3. Batch Size 决定一次迭代处理多少样本。
4. Epoch 表示完整遍历训练集一次。
5. 训练过程通常包含前向传播、计算损失、反向传播和参数更新。
6. PyTorch 默认会累积梯度，因此通常需要调用 "optimizer.zero_grad()"。
7. 不同学习率的效果需要通过控制变量实验和真实结果进行比较。
