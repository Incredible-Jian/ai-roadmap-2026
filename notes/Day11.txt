1. 交集边界：左上角取 max，右下角取 min。
   没有重叠时，交集宽或高限制为 0。

2. IoU = 交集面积 / 并集面积。
   并集 = 面积A + 面积B - 交集。
   IoU 范围是 [0, 1]，框太大、太小或偏移都会降低 IoU。

3. 伪框是估计结果。
   包含目标或标注点，不代表框的范围准确；
   反复优化也不保证伪框完全正确。
4. 训练顺序：
   train → zero_grad → 前向 → loss → backward → step。
   验证使用 eval 和 torch.no_grad。

5. 二分类：
   BCEWithLogitsLoss 直接接收 logits。
   sigmoid 用于把 logits 转成概率。

6. 网络形状：
   Linear 改变每个样本的特征维度，ReLU 不改变形状。
   没有非线性激活，多层 Linear 仍可合并成一层。

7. 检测框：
   分类正确不代表定位准确。
   IoU = 交集面积 / 并集面积。
   点标注缺少目标范围，伪框是估计结果。
8. 每个 batch 更新一次参数；一个 epoch 包含多个 batch。
9. batch 大小不同时，平均 loss 要按样本数加权。
10. 训练过程平均 loss，不保证等于训练结束后重新评估的 loss。
