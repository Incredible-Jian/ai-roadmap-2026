## 1. 图像张量与索引

图像批量输入的常用形状为：

[N, C, H, W] = [样本数量, 通道数量, 高度, 宽度]

- 灰度图通常为 1 个通道，RGB 图通常为 3 个通道。
- unsqueeze(0) 在最前面增加长度为 1 的维度，不改变原有像素值。
- 一张 6×6 灰度图：[6,6] → [1,6,6] → [1,1,6,6]。
- inputs[0]：取第 0 张图片。
- inputs[0,0]：取第 0 张图片的第 0 个通道。
- 下标从 0 开始，位置 (1,1) 对应第二行、第二列。

## 2. 卷积计算与我的易错点

一个输出值，是整个窗口内对应位置相乘后全部求和，
如果有偏置，再加上偏置。

易错点：只算了一行。
单通道 3×3 卷积窗口需要把九项乘积全部相加。

同一组卷积权重在不同位置重复使用，称为权重共享。
输出通道数表示输出特征图数量，不直接等于类别数。

## 3. 手工卷积实验

输入：6×6 灰度图，左半部分为 1，右半部分为 0。
设置：3×3 核、stride=1、padding=0、无偏置。

输出形状：[1,1,4,4]。
原因：窗口在高、宽方向各有 6-3+1=4 个合法位置。

- 核每行为 [-1,0,1]：
  输出每行为 [0,-3,-3,0]，ReLU 后全部为零。
- 核每行为 [1,0,-1]：
  输出每行为 [0,3,3,0]，ReLU 后不变。

负响应不代表计算出错。
ReLU 把负数变为零，不改变张量形状。

## 4. CNN 分类实验

任务：区分带噪声的横、竖条纹。
标签：0 为竖条纹，1 为横条纹。

设置：
- 随机种子：42。
- 图片：600 张，单通道，16×16。
- 训练 / 验证 / 测试：360 / 120 / 120。
- batch_size：32。
- 优化器：Adam，学习率 0.003。
- 损失：BCEWithLogitsLoss。
- 训练：20 个 epoch。
- 根据验证损失保存最佳模型，恢复后重新评估。

模型与形状：

输入       [N,1,16,16]
Conv2d     [N,4,16,16]
ReLU       [N,4,16,16]
MaxPool2d  [N,4,8,8]
Flatten    [N,256]
Linear     [N,1]

需要继续巩固：
- padding=1 在本实验中使卷积前后高宽不变。
- MaxPool2d(2) 缩小高宽，不改变通道数。
- Flatten 保留样本维度，展开每张图片的特征。
- 4×8×8=256，因此 Linear 输入为 256。
- BCEWithLogitsLoss 直接接收 logits，不提前做 sigmoid。

## 6. 训练流程与明日继续内容

训练流程：

zero_grad → 前向计算 → loss → backward → step

- backward() 计算梯度。
- optimizer.step() 更新优化器中包含的参数，包括卷积核。
- 手工卷积实验直接指定核；CNN 实验通过训练学习核。
