Day9：二分类与训练流程

一、写代码的思路

设置随机种子与超参数
→ 准备数据、检查形状
→ 划分训练/验证/测试集
→ 定义模型、损失函数、优化器
→ 训练并验证，保存最佳参数
→ 恢复最佳参数
→ 测试集最终评估
→ 绘图解释结果。

先问清楚三个问题：
输入是什么？输出是什么？用什么损失衡量错误？

本次输入为 [N, 2]，标签与模型输出均为 [N, 1]。
标签规则：x1+x2>0 为 1，否则为 0。

二、一轮训练的核心顺序

model.train()                # 训练模式
optimizer.zero_grad()        # 清除旧梯度
logits = model(x_train)      # 前向计算
loss = criterion(logits, y_train)
loss.backward()             # 计算梯度
optimizer.step()            # 更新参数

随后用 model.eval() 和 torch.no_grad() 评估训练、验证指标。
验证损失更低时，深拷贝并保存参数。

容易混淆：
backward() 计算梯度；step() 才更新参数。
eval() 改变部分层的行为；no_grad() 关闭梯度记录。
恢复检查点是加载已有参数，不是重新学习参数。

三、二分类最重要的搭配

模型输出 logit：任意实数。
Sigmoid 将 logit 转为属于 1 类的概率。

训练：
loss = nn.BCEWithLogitsLoss()(logits, labels)

预测：
p = torch.sigmoid(logits)
prediction = (p >= 0.5).float()

BCEWithLogitsLoss 内部已合并 Sigmoid 与交叉熵的计算，
直接接收 logits，数值更稳定，不要提前做 Sigmoid。

本次阈值规则：
logit>=0 → p>=0.5 → 预测为 1。

四、我需要记牢的区别

1. 准确率与损失

准确率只看类别是否正确。
交叉熵还看给真实类别分配的概率。
因此准确率不变，损失仍可能下降。
准确率 100%，不代表损失为 0。

2. 有限测试集与真实边界

两条边界不同，只要测试样本没落在分类分歧区域，
测试准确率仍可能是 100%。

本次学到：
z≈3.4938*x1+3.5295*x2-0.1115。

真实边界：x1+x2=0。
模型边界：z=0。

反例 (0, 0.001)：
真实类别为 1，模型却预测为 0。
说明测试集全对，不代表所有输入都对。

3. 验证集与测试集

训练集更新参数。
验证集选择模型。
测试集用于最终评估，不根据它反复调参。

本次固定训练 200 轮，保存最佳模型，没有提前停止。
测试准确率 100%，测试损失约 0.1408。

五、我不熟悉的绘图与索引

绘图顺序：
准备数据 → 创建画布 → 画点/线 → 添加说明 → 保存 → 关闭。

fig, ax = plt.subplots()：创建图片和坐标区域。
ax.scatter()：画散点。
ax.plot()：画线。
ax.legend()：显示图例。
fig.savefig()：保存。
plt.close(fig)：关闭。

索引：
x[:, 0]：所有样本的第一个特征。
mask = (labels == 0)：创建选择条件。
x[mask]：真正选出符合条件的样本。

unsqueeze(1)：本实验中 [N] → [N, 1]。
squeeze(1)：本实验中 [N, 1] → [N]。

不用先背绘图参数，先理解每段代码在画什么。
