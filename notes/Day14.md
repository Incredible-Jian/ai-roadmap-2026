# Day14：三分类 CNN 与混淆矩阵

## 只记四件事

1. **标签和模型输出的形状不同。** 输入 `[32, 1, 16, 16]`；模型输出 `[32, 3]`，每行是一个样本的三个 logits；标签 `[32]`、`torch.int64`，每个样本只存一个类别编号。`CrossEntropyLoss(logits, labels)` 接收原始 logits；预测用 `logits.argmax(dim=1)`。
2. **斜条纹来自坐标差。** `columns` 是 `[1,16]`，`rows` 是 `[16,1]`，相减广播为 `[16,16]`，每格是「列号 − 行号」。`((columns - rows - offset).abs() <= 1).float()` 画出有宽度的斜条纹。`position=7` 时 `offset=0`，把条件改为 `== 0` 会保留主对角线的 16 个像素，每行一个。
3. **混淆矩阵先读行，再读列。** 行是真实、列是预测；类别 `0=竖、1=横、2=斜`。三张真实横条纹被预测成竖条纹，就给 `matrix[1, 0]` 累加 3。
4. **调试顺序：** 先打印一批 `images / logits / labels` 的形状、标签类型和类别编号；再看验证损失选出的模型；最后核对测试矩阵总数与测试集大小，以及对角线之和是否等于预测正确的总数。

训练流程：`model.train()` → 清梯度 → 前向 → 算损失 → 反传 → 更新参数。每轮用验证损失选模型，恢复最优参数后再评估测试集。

**验收：通过。** 测试矩阵 `[[49,0,0],[0,34,0],[0,0,37]]`，共 120 张且全部分类正确。这说明模型在本次合成条纹测试集上表现良好。
